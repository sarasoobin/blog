# 공간수정·호스트 온보딩·디버깅에서 배운 것

### 22. `diff` = 변경 전후 "차이"

`-`(빨강)=삭제된 줄, `+`(초록)=추가된 줄, 표시 없음=안 바뀜(맥락). 한 줄 "수정"은 `-`옛줄 + `+`새줄로 보인다. **코드 리뷰 = 전체가 아니라 diff(바뀐 것)만 읽는 것.** `git diff` / GitHub "Files changed".

### 23. 화살표 함수: 한 줄 vs 블록 `{ }`

여러 줄(문장 여러 개)을 쓰려면 **`{ }` 블록**으로 감싸야 한다. 안 그러면 세미콜론에서 깨진다.

```tsx
onClick={() => navigate("/x")}       // 한 줄: 표현식 하나, 그대로
onClick={() => {                     // 여러 줄: { } 블록 필수
  setEdit(false);
  navigate("/x");
}}                                   // 끝은 }} (블록 } + JSX })
```

### 24. import는 "쓰는 것과 딱 맞아야" (tsc가 양쪽 다 잡음)

- **안 쓰는데 import** → `'X' is declared but never used`
- **쓰는데 import 안 함** → `Cannot find name 'X'`
- **주석은 "사용"으로 안 침** — 변수를 주석에만 남기면 "안 쓰는 변수"로 걸린다.

우리 프로젝트는 `noUnusedLocals`라 이걸로 **빌드까지 막는다.** (실제로 배포 깨짐의 원인이 됨)

### 25. 조건부 렌더링 `{조건 && (...)}` — "감싸기"

기존 JSX를 **다시 쓰지 말고** 위·아래 한 줄씩만 넣어 감싼다.

```tsx
{needsFloorNumber && (        // ← 이 줄 추가 (반지층·옥탑이면 숨김)
  <div className="relative">
    {/* ...기존 그대로... */}
  </div>
)}                            // ← 이 줄 추가
```

⚠️ 화면을 숨기면 **유효성 검사도 같이** 손봐야 함 — 숨긴 필드를 필수로 요구하면 "다음" 버튼이 영영 안 켜진다. (`(!needsFloorNumber || form.floor !== "")`)

### 26. Tailwind hover + 터치 대응

- `group`(부모) + `group-hover:`(자식) = "부모에 hover하면 자식이 변함" (사진 위 삭제 오버레이).
- **`opacity-0`은 안 보이게만 할 뿐, 클릭은 됨** → 터치 기기에선 안 보이는 버튼을 탭해 사고. `[@media(hover:hover)]:opacity-0`로 **hover 되는 기기에서만 숨기고, 터치 기기는 항상 노출.**

### 27. ⭐ 정적검사 통과 ≠ 로직 맞음

`!`(NOT) 하나 빠져도 tsc·eslint는 통과한다(문법·타입은 멀쩡). **의미가 맞는지는 브라우저에서 직접 클릭 테스트**로만 확인된다. "초록불 = 완료"가 아니라 "초록불 + 눈으로 동작 확인 = 완료".

### 28. 설계도(interface) vs 실물(store) 일치

Zustand에서 `interface`에 필드를 추가하면 **실제 store 객체에도** 넣어야 한다. 안 맞으면 tsc가 `missing properties: ...`로 잡아준다. (약속 ↔ 물건 대조)

### 29. Zustand "스위치(플래그)" 패턴

`isEdit`(공간수정), `hasSeenHostIntro`(호스트 온보딩 1회)처럼 **boolean 하나**로 같은 화면을 여러 용도로 쓴다.

- 진입점에서 플래그 ON → 화면은 플래그로 제목·문구 분기 → 완료/이탈 시 리셋.
- 메모리 기반이라 **새로고침 시 초기화**됨(persist 없음).

### 30. dev 서버 재시작이 필요할 때

**새 라우트/새 파일**을 추가하면 Vite HMR이 못 잡을 때가 있다 → `Ctrl+C` 후 `pnpm dev` 재시작 + 강력 새로고침(Ctrl+Shift+R). **"코드는 맞는데 화면이 안 바뀔 때" 1순위로 의심.**

### 31. 자잘한 JS 문법 (자주 나옴)

```ts
next[0] ?? ""                  // 널 병합: 왼쪽이 null/undefined면 오른쪽
hidesFloor ? "" : form.floor   // 삼항: 조건 참이면 A, 아니면 B
a === "반지층" || a === "옥탑"  // OR: 하나라도 참
setValues({ floorType })       // 속성 shorthand = { floorType: floorType }
```

### 32. 라우터 "연결"의 두 가지 의미

- **router.tsx에 라우트 등록** (`{ path, element }`) — 경로 ↔ 컴포넌트 연결
- **버튼 → 그 경로로 navigate** — 트리거 연결

호스트 온보딩은 라우트(`HostRegisterStart`)는 **이미 있었고**, Header 버튼의 `navigate`만 연결한 것. "라우터 연결"이라고 다 router.tsx를 고치는 건 아니다.
